## Stage-by-Stage Milestones

### Stage 00: How to Study (Week 1 / Days 1–6)
- **Focus:** Learning science, chunking, active recall, note-taking templates, Anki flashcards, AI usage rules.
- **Key Milestone:** A fully configured personal study system with `progress/README.md` initialized, Anki deck created, and a daily study routine established.
- **Guide:** [`resources/00-how-to-study.md`](resources/00-how-to-study.md)

### Stage 01: HTML & CSS (Weeks 2–4 / Days 7–24)
- **Focus:** Semantic HTML5, document outline, accessibility (ARIA, semantic landmarks), CSS box model, Flexbox, CSS Grid, mobile-first responsive design, forms.
- **Key Milestone:** Build and deploy a multi-page, responsive, accessible website (Home, About, Contact) from scratch without using any CSS frameworks.
- **Guide:** [`resources/01-html-css.md`](resources/01-html-css.md)

### Stage 02: JavaScript Fundamentals (Weeks 5–8 / Days 25–48)
- **Focus:** Data types, variables, type coercion, operators, conditional branching, loops, functions, scope, objects, arrays, and algorithmic problem-solving.
- **Key Milestone:** Build a command-line utility or interactive logic application (e.g., terminal task manager, expense calculator) using pure vanilla JavaScript.
- **Guide:** [`resources/02-javascript-fundamentals.md`](resources/02-javascript-fundamentals.md)

### Stage 03: Modern JavaScript (Weeks 9–11 / Days 49–66)
- **Focus:** ES6+ features, `let`/`const`, template literals, arrow functions, destructuring, spread/rest operators, ES Modules (`import`/`export`), array methods (`map`, `filter`, `reduce`), immutability.
- **Key Milestone:** Refactor previous code into modular, functional ES modules utilizing pure functions and modern immutable array transformations.
- **Guide:** [`resources/03-modern-javascript.md`](resources/03-modern-javascript.md)

### Stage 04: DOM & Browser APIs (Weeks 12–14 / Days 67–84)
- **Focus:** DOM traversal, node manipulation, event handling, event delegation, form validation, Web Storage API (`localStorage`, `sessionStorage`), timers.
- **Key Milestone:** Build a fully interactive, persistent browser application (e.g., kanban board, shopping cart, interactive quiz) with `localStorage` persistence.
- **Guide:** [`resources/04-dom-browser-apis.md`](resources/04-dom-browser-apis.md)

### Stage 05: Asynchronous JavaScript (Weeks 15–17 / Days 85–102)
- **Focus:** Synchronous vs asynchronous execution, event loop, callback hell, Promises, `async`/`await`, the `fetch` API, HTTP status handling, loading & error UI states.
- **Key Milestone:** Build a dynamic API-driven application (e.g., weather dashboard, GitHub user explorer, movie search app) with real-time feedback, debounce, and error handling.
- **Guide:** [`resources/05-async-javascript.md`](resources/05-async-javascript.md)

### Stage 06: Git & GitHub (Week 18 / Days 103–108)
- **Focus:** Git basics, repository initialization, staging, commit messages, branching strategies, merge conflicts, GitHub remotes, Pull Requests, GitHub Pages deployment.
- **Key Milestone:** Publish all previous projects to GitHub with professional `README.md` documentation, clean commit histories, and live deployment links.
- **Guide:** [`resources/06-git-github.md`](resources/06-git-github.md)

### Stage 07: React Fundamentals (Weeks 19–22 / Days 109–132)
- **Focus:** Why React exists, JSX syntax, component composition, props, state with `useState`, event handling, conditional rendering, lists and keys, controlled form inputs.
- **Key Milestone:** Build an interactive single-page application (e.g., recipe manager, personal finance tracker) in React with clean component architecture using Vite.
- **Guide:** [`resources/07-react.md`](resources/07-react.md)

### Stage 08: React Hooks & Advanced React (Weeks 23–25 / Days 133–150)
- **Focus:** The `useEffect` hook, side effects, cleanup functions, `useRef`, custom hooks, Context API for global state, `useReducer` for complex state, client-side routing.
- **Key Milestone:** Build a multi-page React application with client-side routing, shared authentication/theme state via Context, and custom reusable data-fetching hooks.
- **Guide:** [`resources/08-react-hooks.md`](resources/08-react-hooks.md)

### Stage 09: Portfolio Projects (Weeks 26–28 / Days 151–168)
- **Focus:** End-to-end project planning, design translation, state management, deployment, responsive audits, accessibility testing, and portfolio presentation.
- **Key Milestone:** Deliver 3 polished, production-grade portfolio projects:
  1. *Project 1:* Responsive Marketing Landing Page (HTML/CSS/JS)
  2. *Project 2:* Interactive Data Dashboard (React + External REST API)
  3. *Project 3:* Complete Feature-Rich Web App (React + Persistent Backend/Firebase/Supabase)
- **Guide:** [`resources/09-projects.md`](resources/09-projects.md)

### Stage 10: TypeScript (Weeks 29–31 / Days 169–186)
- **Focus:** Static typing, type inference, primitive types, interfaces, type aliases, unions, generics, typing functions and events, typing React components, props, and hooks.
- **Key Milestone:** Migrate an existing React application to TypeScript with strict type-checking enabled (`strict: true`) and zero `any` types.
- **Guide:** [`resources/10-typescript.md`](resources/10-typescript.md)

### Stage 11: Next.js (Weeks 32–35 / Days 187–210)
- **Focus:** Full-stack React, Next.js App Router, file-system routing, layouts, Server Components vs Client Components, server-side data fetching, SEO optimization, deployment to Vercel.
- **Key Milestone:** Build and deploy a complete full-stack web application with dynamic routing, Server-Side Rendering (SSR), API routes or Server Actions, and database integration.
- **Guide:** [`resources/11-nextjs.md`](resources/11-nextjs.md)

## The Golden Rules of the Roadmap

1. **Never Skip Ahead to React:** React is 90% JavaScript. If you do not understand closures, array methods, and async operations, React will feel like magic rather than code.
2. **Commit Daily:** Consistency beats intensity. 90 minutes of daily coding creates compound learning that weekly 10-hour marathons cannot replicate.
3. **Build from Scratch:** Copying code from tutorials teaches you how to copy code. Building from a blank editor teaches you how to think like an engineer.

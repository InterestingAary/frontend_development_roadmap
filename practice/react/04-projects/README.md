# Practical Project Guidance

Move from tutorials to real building by completing projects in levels.

## Beginner projects

### 1) Calculator
- **Skills practiced:** conditionals, events, state updates
- **Suggested features:** basic operators, clear button, keyboard support
- **Possible improvements:** input history, theme switch

### 2) To-do app
- **Skills practiced:** arrays, DOM/React rendering, localStorage
- **Suggested features:** add/edit/delete, mark complete, filters
- **Possible improvements:** due dates, drag and drop ordering

### 3) Quiz app
- **Skills practiced:** objects/arrays, conditional rendering, score logic
- **Suggested features:** multiple questions, score summary, restart
- **Possible improvements:** timer, category selection

### 4) Digital clock
- **Skills practiced:** Date APIs, intervals, component updates
- **Suggested features:** live time, 12h/24h mode, date display
- **Possible improvements:** world time zones

### 5) Notes app
- **Skills practiced:** forms, CRUD operations, persistence
- **Suggested features:** create/edit/delete notes, search notes
- **Possible improvements:** markdown preview, tags

## Intermediate projects

### 1) Weather dashboard
- **Skills practiced:** fetch, async/await, loading/error UI
- **Suggested features:** city search, current weather, forecast
- **Possible improvements:** geolocation, saved cities

### 2) GitHub profile finder
- **Skills practiced:** API integration, controlled inputs, conditional UI
- **Suggested features:** search user, show avatar/repos/followers
- **Possible improvements:** recent activity feed

### 3) Movie search app
- **Skills practiced:** debouncing, API queries, state management
- **Suggested features:** search movies, detail view, pagination
- **Possible improvements:** favorites and watchlist

### 4) Expense tracker
- **Skills practiced:** state modeling, derived values, charts basics
- **Suggested features:** add transactions, totals by category
- **Possible improvements:** monthly reports, CSV export

### 5) E-commerce product page
- **Skills practiced:** component composition, filters, cart logic
- **Suggested features:** product listing, size/color options, cart preview
- **Possible improvements:** persistent cart and mock checkout

## Advanced projects

### 1) Admin dashboard
- **Skills practiced:** reusable architecture, routing, data dashboards
- **Suggested features:** analytics cards, tables, filters
- **Possible improvements:** role-based UI, audit logs

### 2) Real-time chat UI
- **Skills practiced:** state synchronization, async updates, UX handling
- **Suggested features:** channels, message input, typing indicator
- **Possible improvements:** websocket backend integration

### 3) Full e-commerce frontend
- **Skills practiced:** routing, global state, checkout flow
- **Suggested features:** product pages, cart, checkout, auth UI
- **Possible improvements:** order history, wishlists

### 4) AI-powered productivity app
- **Skills practiced:** API orchestration, prompt UX, async states
- **Suggested features:** task summarization, notes assistant
- **Possible improvements:** personalized recommendations

### 5) Learning management system (LMS)
- **Skills practiced:** complex UI states, modular design, data modeling
- **Suggested features:** course list, lesson pages, progress tracking
- **Possible improvements:** quizzes, instructor/admin roles

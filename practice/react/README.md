# React Practice Files

These are beginner-friendly React examples you can copy into a React app created with Vite.

## Quick start

1. Create a new app:
   - `npm create vite@latest my-react-practice -- --template react`
2. Install dependencies:
   - `cd my-react-practice`
   - `npm install`
3. Replace `src/App.jsx` with one example at a time.
4. Run the app:
   - `npm run dev`

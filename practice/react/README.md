# React Practice Guide

These files are educational examples, not a full React app by themselves.

## Setup once (Vite)

1. `npm create vite@latest my-react-practice -- --template react`
2. `cd my-react-practice`
3. `npm install`
4. `npm run dev`

## How to use these files

1. Pick one file from this repository.
2. Copy it into `src/App.jsx` (or import it in `App.jsx`).
3. Run the app and test interactions.
4. Edit the example and observe re-renders in React DevTools.

## Why this matters

- React files need a bundler and JSX transform.
- Practicing one concept at a time reduces confusion.
- Rewriting each example from memory improves retention.

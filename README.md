## 1. What Is This Repository?

This repository is an **open-source, self-guided frontend development learning curriculum**. It is not a code dump, not a website template, and not a massive Next.js application.

The repository **is** the curriculum: a structured roadmap with curated, high-quality resources, day-by-day study instructions, practical milestone projects, and progress tracking templates designed to take a learner from total beginner to job-ready frontend developer.

---

## 2. Who Is This Curriculum For?

This curriculum is built for:
- **Complete beginners** with zero programming experience who want a clear, step-by-step path into web development.
- **Self-taught developers** suffering from "tutorial hell" who need structured practice, deliberate project building, and accountability.
- **Students and career switchers** who want deep technical foundations rather than surface-level framework hype.
- **Junior developers** who learned a framework (like React) but feel gaps in vanilla JavaScript, DOM manipulation, asynchronous programming, or accessibility.

## 5. How Long Will It Take?

The curriculum consists of **210 daily study lessons across 35 weeks**. Daily study sessions are calibrated to **90 minutes per day, 6 days per week** (~9 hours per week).

Depending on your daily schedule, choose one of these mathematically consistent paces:

| Pace Tier | Weekly Commitment | Daily Time Commitment | Total Calendar Duration | Who This Is For |
|-----------|:-----------------:|:--------------------:|:-----------------------:|-----------------|
| **Standard Pace** | 9–12 hours / week | 90 minutes / day (6 days/week) | **35 weeks** (~8.5 months) | Recommended pace for most learners with full-time jobs or school. |
| **Accelerated Pace** | 18–20 hours / week | 3–3.5 hours / day (6 days/week) | **18–20 weeks** (~4.5 months) | For full-time learners, bootcamp students, or career transitions. |
| **Relaxed Pace** | 5–6 hours / week | ~60 minutes / day (5–6 days/week) | **50–52 weeks** (~1 year) | For busy professionals learning consistently in small daily chunks. |

> **Remember:** Coding is a marathon of consistency, not a weekend sprint. Move to the next stage only when you can satisfy every item on that stage's **Completion Checklist**.

## 9. Core Technical Principles

To develop sound engineering intuition, keep these fundamental truths in mind:

1. **HTML is markup, not a programming language.** It provides semantics, structure, and accessibility for content.
2. **CSS is styling, not markup.** It handles presentation, layout, responsive adaptations, and visual states.
3. **JavaScript is a programming language.** It brings computation, behavior, interactivity, and business logic to web applications.
4. **React is a JavaScript library for building user interfaces.** React does not replace JavaScript. React code is JavaScript. Without solid JS fundamentals, React will be confusing.
5. **JavaScript fundamentals are strictly required before learning React.** Component state, props, JSX mapping, and hooks rely entirely on JS closures, object immutability, array methods, and scope.
6. **TypeScript builds on JavaScript.** TypeScript adds static type checking to JavaScript. It compiles down to plain JavaScript.
7. **Next.js builds on React.** Next.js is a full-stack framework providing routing, rendering strategies, and server integration on top of React.
8. **Git and GitHub are version control tools, not programming languages.** They allow you to track changes, collaborate, and showcase your source code.
9. **No hype, no shortcuts.** Frameworks come and go, but the web platform (HTML, CSS, JavaScript, HTTP, and browser APIs) remains. Master the fundamentals and you will be able to learn any framework in days.
